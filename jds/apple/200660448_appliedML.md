# Applied Machine Learning Engineer - Developer Publications

## About the Role

Apple’s Developer Publications Intelligence team is looking for an Applied Machine Learning Engineer with strong knowledge of large language models, machine learning infrastructure, and large-scale LLM evaluation.

You will join a multidisciplinary team of machine learning and software engineers building and integrating ML models into current and future Apple tools for third-party developers.

The role involves collaborating with domain experts and other Apple departments while contributing to system architecture, technical proposals, code reviews, and engineering best practices.

## Responsibilities

* Build and integrate machine learning models into tools for third-party Apple developers.
* Drive MLOps and LLMOps practices within the team.
* Design, build, and maintain LLM evaluation pipelines.
* Assess model quality and track regressions.
* Support continuous model-improvement cycles.
* Implement monitoring, observability, and deployment best practices.
* Participate in code reviews and pair-programming sessions.
* Contribute to architecture discussions and technical proposals.
* Collaborate with machine learning engineers, software engineers, domain experts, and other Apple teams.

## Minimum Qualifications

* Strong programming skills in Python, Swift, Go, or another relevant language.
* Experience with MLOps or LLMOps frameworks and toolkits.
* Comprehensive knowledge of LLM evaluation.
* Hands-on experience building or operating LLM evaluation systems.
* Strong software engineering fundamentals.
* Willingness to continuously learn and improve both individual and team practices.

## Preferred Qualifications

* Bachelor’s, master’s, or PhD degree in Computer Science, Artificial Intelligence, Machine Learning, or equivalent professional experience.
* Experience using Xcode.
* Experience programming in Swift.
* Experience developing applications or tools for Apple platforms.
* Familiarity with on-device large language models.
