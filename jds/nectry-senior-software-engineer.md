## Company / Product Context

Nectry is building the governance layer for AI-generated code in regulated enterprises. Its core technology, NectryCore, is a purpose-built DSL and compiler that makes formal verification and policy enforcement structurally guaranteed rather than bolted on.

The team is small and ambitious. They are looking for an engineer who loves type systems, takes ownership, and wants to use AI tools to build software that has to be correct.

## The Role

The role works across language design, tooling, and product engineering. Most application code is written in Ur/Web, a statically typed functional language for web programming. Ur/Web experience is not expected on day one, but the company expects an engineer who can pick up an unfamiliar functional language quickly.

This is a senior, high-autonomy role. The engineer will scope their own work, own systems end to end, and shape technical direction alongside the co-founders, including Chief Scientist Adam Chlipala.

## What You'll Do

- Build product features and infrastructure, primarily in Ur/Web, with excursions into other languages as needed.
- Contribute to the design and implementation of NectryCore: the DSL, compiler, and verification tooling.
- Use AI coding tools heavily and help define how senior engineers should work with them on code that has to be correct.
- Work directly with customers, including federal and regulated-industry users, to turn real requirements into well-typed software.
- Make decisions, push back, and improve how the team builds.

## Why Nectry

Nectry argues that AI is generating more software than ever, and much of it carries risk into systems that cannot afford loose reasoning. At Nectry, correctness is not treated as a cost center or something added through tests and review. It is the product.

The company values code that ships, is well structured, well typed, and worth reading. The team includes people who have built compilers, proved cryptographic protocols correct, and care deeply about engineering craft.

## Required

- 5+ years of relevant software engineering experience.
- Genuine enthusiasm for functional programming, ideally with production or substantial project experience in Haskell, OCaml, or a similar typed FP language.
- Strong fundamentals in type systems, program semantics, and writing code that is easy to reason about.
- Eagerness to work with AI coding tools as a serious part of daily workflow.
- Self-motivated and comfortable operating with minimal supervision in a small, distributed team.
- Excellent written communication; the team is remote and async-friendly.

## Nice To Have

- Experience with Ur/Web, Rocq, Lean, Agda, Idris, or other dependently typed systems.
- Compiler, programming language, or formal methods background.
- Experience shipping software in regulated environments such as FedRAMP, IL4/IL5, HIPAA, or SOC 2.
- Experience building developer tools, DSLs, or platforms.
- Background in security, identity, or authorization systems.
- Web design and frontend experience, including clean UI and polished usable interfaces.
